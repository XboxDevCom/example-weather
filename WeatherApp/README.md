# Example: Wetter-App

This is a weather app example running with UWP technology on the Xbox One, demonstrating HTTP API calls.

## Getting Started

Please follow our [tutorial](https://xboxdev.com/tutorials/) to create your own weather application.

## Built with

* [Visual Studio](https://visualstudio.microsoft.com/) - C# Editor from Microsoft
* [Xbox One](https://afflnk.microsoft.com/c/1256010/476314/7806/) - Testing the application
* [Microsoft.NETCore.UniversalWindowsPlatform](https://www.nuget.org/packages/Microsoft.NETCore.UniversalWindowsPlatform/) - UWP platform package
